Политика конфиденциальности Muslingo

Образовательное приложение для изучения Корана, арабского языка и основ ислама

Последнее обновление: уточняется. Оператор: команда Muslingo. Контакт: support@muslingo.app.

Мы стремимся собирать минимум данных, необходимых для работы приложения. Приложением можно пользоваться без регистрации — тогда прогресс хранится только на вашем устройстве.

1. Какие данные мы обрабатываем

  • Аккаунт (если регистрируетесь): имя, email и пароль. Пароль хранится только в виде криптографического хеша, в открытом виде мы его не храним.
  • Учебный прогресс: XP, уровень, серия дней, пройденные уроки, слабые места, настройки. У гостя — локально; у зарегистрированного — синхронизируется с нашим сервером.
  • Произношение: упражнения используют встроенное в вашу ОС распознавание речи (Apple/Google). Muslingo не записывает и не хранит аудио вашего голоса — на сервер для оценки передаётся только распознанный текст и целевая фраза, не звук.
  • Напоминания: при включении храним данные push-подписки, часовой пояс и выбранное время — только чтобы присылать напоминания об уроке.
  • Технические данные: стандартные логи запросов (включая IP — для базовой защиты от злоупотреблений).

Мы не собираем геолокацию, контакты, фото, данные здоровья и рекламные идентификаторы. Рекламы и сторонних трекеров нет.

2. Зачем используем

Обучение и сохранение прогресса; оценка произношения; синхронизация между устройствами; напоминания; соревнование с друзьями по коду (друзьям видны только имя, XP и серия — не email); безопасность. Мы не продаём ваши данные и не используем их для рекламного профилирования.

3. Вход через Apple и Google

При использовании входа через Apple/Google они передают нам ограниченные данные (имя, email) для создания аккаунта. Их обработка регулируется политиками Apple и Google.

4. Третьи стороны (обработчики)

  • Хостинг и API — Vercel; база данных — Neon (PostgreSQL).
  • Распознавание речи — Apple/Google на уровне ОС.
  • Аудио Корана — публичные CDN (cdn.islamic.network, everyayah.com и др.).
  • Доставка push — сервисы платформы (FCM, Apple, Mozilla).

5. Хранение и удаление

Данные аккаунта хранятся, пока существует аккаунт. Вы можете:

  • Удалить аккаунт прямо в приложении (Профиль → Настройки → Удалить аккаунт) — удаляются данные аккаунта, прогресс, дружеские связи и push-подписки.
  • Отключить напоминания в настройках.
  • Для гостя — очистить локальные данные через «Начать заново».

Запрос на удаление можно направить на support@muslingo.app.

6. Дети

Приложение не предназначено для детей младшего возраста и не собирает намеренно их персональные данные. Если вы считаете, что нам попали данные ребёнка, напишите нам — мы их удалим.

7. Ваши права

В зависимости от юрисдикции вы можете иметь право на доступ, исправление, удаление и перенос данных. Для реализации напишите на support@muslingo.app.

8. Безопасность

Соединение с сервером шифруется (HTTPS), пароли хранятся в виде хеша, применяется ограничение попыток входа. Абсолютной безопасности в интернете не существует, но мы стремимся защищать ваши данные.

9. Изменения

Мы можем обновлять эту политику; существенные изменения будут отражены здесь с новой датой обновления.

Вопросы по конфиденциальности: support@muslingo.app.
